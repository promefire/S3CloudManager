## 实现计划：图片缩略图视图 + 放大预览

### 需求总结
1. 新增「缩略图视图」模式，与现有「列表视图」可切换
2. 两种视图下点击图片都能弹出放大预览
3. 保持现有 UI 风格（Materialize CSS + 蓝色主题）

### 修改文件
仅修改 `S3CloudManager-front/src/components/Bucket.vue`

---

### 具体改动

#### 1. 新增数据状态
```js
viewMode: 'list',       // 'list' | 'thumbnail'
previewImage: null,     // 当前预览的图片对象
```

#### 2. 视图切换按钮
在「上传文件 / 新建文件夹 / 多选」按钮旁新增一个切换按钮：
- 列表视图时显示「网格」图标，点击切换到缩略图
- 缩略图视图时显示「列表」图标，点击切换回列表

#### 3. 缩略图网格视图（替代原有 table）
当 `viewMode === 'thumbnail'` 时，用 `row` + `col` 网格布局展示：
- **图片文件**：用 `<img>` 标签直接加载 `IMAGE_DOMAIN/{key}` 作为缩略图，下方显示文件名
- **非图片文件**：显示大图标 + 文件名
- **文件夹**：显示文件夹图标 + 名称，点击可进入
- 每个卡片固定宽度（如 `col s6 m4 l3`），自适应布局
- 卡片有 hover 效果（阴影 + 高亮）

#### 4. 图片放大预览（Lightbox）
新增一个全屏遮罩层，点击图片时弹出：
- 深色半透明背景
- 居中显示大图（max-width/max-height 限制）
- 顶部栏：显示文件名 + 关闭按钮 + 复制链接按钮
- 支持键盘 ESC 关闭
- 点击背景关闭

#### 5. 修改点击逻辑
- 图片文件：原来 `window.open(url, '_blank')` → 改为打开预览 modal
- 文件夹：保持不变（导航进入）
- 其他文件：保持不变

#### 6. 新增 CSS 样式
- 缩略图网格卡片样式（圆角、阴影、hover 动画）
- Lightbox 遮罩层样式
- 响应式适配

---

### 不改动的部分
- 后端代码无需修改
- 路由配置不变
- 其他组件不变
- API 接口不变
