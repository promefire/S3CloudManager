### 修改文件清单

#### 1. `src/App.vue` — 核心修改

**Header 模板重构：**
- 将 Materialize `<nav>` 替换为自定义 `.app-header`
- 左侧：云图标 + "S3 Storage"
- 右侧：用户头像 + 用户名 + 下拉菜单（包含退出登录）
- 高度 64px，白色背景，底部细边框

**全局样式重构：**
- 添加 `:root` CSS 变量
- 更新 `body` 背景为 `#F8FAFC`
- 减少 `!important` 覆盖，改用 CSS 变量
- 更新按钮样式（扁平化、小圆角、轻阴影）
- 更新卡片样式
- 更新表格样式
- 更新分页样式

#### 2. `src/components/Bucket.vue` — 局部调整

**导航栏简化：**
- 移除 Materialize `nav-extended` 的蓝色/青色背景
- 改为简洁的白色工具栏 + 面包屑
- 统一按钮风格

#### 3. `src/components/Buckets.vue` — 局部调整

- 更新卡片样式（白底、细边框、轻阴影）
- 统一按钮风格
- 优化 FAB 按钮

---

### 不修改的内容

- 所有 JavaScript 业务逻辑（上传、删除、文件夹、API 调用）
- 路由配置
- 后端接口
- 数据结构
- Materialize CSS / JS 文件本身
- Login.vue 的登录逻辑（仅微调样式）
- HelloWorld.vue
